# 🛡️ CodeGuard AI
### AI-Powered Pull Request Review Assistant

> Detect bugs, security vulnerabilities, and performance issues in pull requests — instantly.

🔗 **Live Demo**: https://ai-code-reviewer-nu-liart.vercel.app/
🌐 **Backend API**: https://ai-code-reviewer-hgyi.onrender.com
📦 **Repository**: https://github.com/chandni5033/ai-code-reviewer
> Free-tier backend hosting may take a few seconds to wake up after inactivity.

---

## 🎯 Problem

Developers spend hours reviewing pull requests manually, and critical bugs, security flaws, and performance issues still slip through. Traditional code review is slow, inconsistent, and entirely dependent on human attention.

## 💡 Solution

CodeGuard AI connects to GitHub and reviews your entire pull request using a large language model — analyzing every changed file for real bugs, security risks, and performance bottlenecks in seconds. It delivers structured, actionable feedback with exact line numbers, syntax-highlighted snippets, and concrete fix suggestions.

## ✨ Features

| Feature | Description |
|---|---|
| 🔗 **GitHub PR Analysis** | Paste any public GitHub PR URL and get instant AI review |
| 📋 **Code Paste Mode** | Paste raw code directly — supports any language |
| 🤖 **AI Summary** | Executive summary of all findings generated by LLM |
| 📁 **Per-File Breakdown** | Issues grouped by file with collapsible accordion UI |
| 🎨 **Syntax Highlighting** | Language-aware code snippets for every issue |
| 🚦 **PR Verdict** | Automatic Approve / Needs Review / Block PR decision |
| 📊 **Risk Score** | 0–100 risk score based on severity and issue count |
| ⚡ **Impact Analysis** | Each issue explains exactly what breaks and when |
| 🔒 **Rate Limiting** | 10 reviews/min per IP — production safe |
| 🌐 **Multi-language** | C++, Python, JavaScript, TypeScript, Java, Go, Rust |
| 🔐 **Private Repo Support** | Coming soon via GitHub OAuth |

---

## 🧠 How It Works

```
User pastes GitHub PR URL
        ↓
Backend fetches diff from GitHub API
        ↓
Diff split into per-file chunks
        ↓
Each file reviewed in parallel via Groq LLM
        ↓
Issues returned with severity, line number,
syntax-highlighted snippet, impact & fix
        ↓
AI generates executive summary
        ↓
Frontend renders verdict + file-level breakdown
```

## 🧠 AI Architecture

CodeGuard uses a **dual-model strategy** for optimal speed and quality:

| Task | Model | Reason |
|---|---|---|
| Code Analysis | `llama-3.1-8b-instant` | Fast lightweight models for parallel file analysis |
| PR Summary | `llama-3.3-70b-versatile` | Larger reasoning models for executive summaries |

Both models are served via **Groq Cloud** — delivering GPT-4 level reasoning 
at sub-second inference speed, making real-time PR review possible.

## 🚀 Local Setup

### Prerequisites
- Node.js 18+
- Groq API key — free at [console.groq.com](https://console.groq.com)
- GitHub Personal Access Token (optional, for higher rate limits)

### Backend

```bash
cd backend
npm install
cp .env.example .env
# Add your keys to .env
node server.js
```

### Frontend

```bash
cd frontend/AI-CODE-REVIEWER-FRONTEND
npm install
npm run dev
```

### Environment Variables

#### Backend `.env`

```env
GROQ_API_KEY=your_groq_api_key_here
GITHUB_TOKEN=optional_for_higher_github_rate_limits
PORT=5000
```

#### Frontend `.env`

```env
VITE_API_URL=http://localhost:5000
```

#### Frontend Production Environment (Vercel)

```env
VITE_API_URL=https://ai-code-reviewer-hgyi.onrender.com
```

## 🔍 What It Detects

- **Bugs** — wrong logic, off-by-one errors, incorrect conditions
- **Security** — hardcoded secrets, injection risks, missing auth checks
- **Performance** — inefficient patterns, unnecessary re-renders, N+1 queries
- **Undefined Behavior** — missing return paths, null dereferences, memory leaks
- **Unhandled Errors** — async calls without try/catch, swallowed exceptions
- **Infinite Loops** — conditions that never become false
- **Race Conditions** — shared mutable state without synchronization

## ⚙️ API Reference

### `POST /review`
Review raw pasted code.

```json
Request:  { "code": "your code here" }
Response: { "review": [...issues], "summary": "AI summary text" }
```

### `POST /fetch-pr`
Fetch and review a GitHub pull request.

```json
Request:  { "prUrl": "https://github.com/owner/repo/pull/123" }
Response: { "review": [...issues], "files": [...], "summary": "...", "meta": {...} }
```

### Issue Object Schema

```json
{
  "severity": "High | Medium | Low",
  "category": "Bug | Security | Performance | Code Smell",
  "line": 42,
  "confidence": 95,
  "issue": "What is wrong and why",
  "impact": "What breaks and when",
  "fix": "Concrete actionable fix",
  "snippet": "Exact code with the problem",
  "filename": "src/auth.js"
}
```
